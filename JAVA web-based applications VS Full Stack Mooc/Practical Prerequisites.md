
## Practical Prerequisites

| Prerequisite | Java Web Server Programming | Full Stack Open |
| :--- | :--- | :--- |
| **Required Knowledge** | Complete University of Helsinki Java Programming MOOC (Parts 1 & 2) **OR** equivalent OOP knowledge (classes, inheritance, interfaces) | Strong programming fundamentals (loops, functions, logic) + solid baseline in JavaScript (objects, arrays, ES6 arrow functions, promises, async/await) |

## How to Sequence Them (If Taking Both)

| Step | Course | What You Gain |
| :--- | :--- | :--- |
| **1** | Java Programming MOOC (Parts 1 & 2) | World-class foundation in object-oriented logic |
| **2** | Web Server Programming Java (2021) | Fundamental backend concepts: routing, database persistence, HTTP semantics |
| **3** | Full Stack Open | Modern, highly interactive UI development, state management, and cloud deployment |

> **Key Insight:** Learning backend through two distinct mental models (Java/Spring vs. Node/Express) gives you a profound understanding of software engineering that extends far past a single language.
