#### Course information
- [ ] Web Server Programming Java is a free and open online course from the University of Helsinki that teaches the basics of web server programming.
- [ ] The course introduces the basic ideas of web applications and their implementation.
- [ ] Attending the course requires knowledge of the courses `Programming Fundamentals (TKT10002)`, `Advanced Programming Course (TKT10003)` and `Database Fundamentals (TKT10004)`, as well as knowledge of the Java programming language or the enthusiasm to learn it during the course.
#### Content and schedule
- The course consists of seven sets of assignments, a programming project, and an exam.
- The estimated workload for the course is approximately 135 hours. You should allow approximately 12 hours for each set of assignments, approximately 40 hours for the project and related peer reviews, and approximately 8 hours for the exam review. We reserve the right to change the schedule and topics.
