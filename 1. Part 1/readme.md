#### Part 1
- After the first part, you will know the main features of how the internet works. You will be familiar with the concepts of `URI`, `DNS`, `HTTP` and `HTML`, as well as the concepts of path and request parameter related to `URI`. You will be familiar with the most important methods of the `HTTP protocol` used by web applications, `GET` and `POST`, and you will be able to recognize some common requests and responses. You will know what the client-server model means. You will be able to implement a simple server and browser in Java. You will also take the first steps in using the **Spring application framework** and create several web applications that respond to requests using **the Spring application framework**.
Here is your **Learning Outcomes for Part 1** of the Web Server Programming Java course, formatted clearly:

| Concept | What You'll Understand |
| :--- | :--- |
| **URI** | What it is and how it identifies resources |
| **DNS** | How domain names map to IP addresses |
| **HTTP** | The protocol that powers web communication |
| **HTML** | The markup language for web pages |
| **Path & Request Parameters** | How they relate to URIs |

#### HTTP Protocol
| Method | Application |
| :--- | :--- |
| **GET** | One of the most important HTTP methods for web apps |
| **POST** | The other essential method for submitting data |

You will be able to recognize common requests and responses using both methods.

#### Architecture Understanding
- **Client-Server Model** – What it means and how it works

#### Practical Implementation Skills
| Skill | What You'll Build |
| :--- | :--- |
| **From Scratch** | A simple server and browser in Java |
| **With Spring Framework** | First steps using Spring application framework |
| **Web Applications** | Multiple apps that respond to requests using Spring |

By the end of Part 1, you move from **theoretical concepts** (HTTP, DNS, client-server) to **practical implementation** (Java server/browser + Spring apps that handle GET/POST requests).
