#### Basic parts of the Internet
- Learning objectives
1. You know the basics of how the Internet works.
2. You are familiar with the concepts of URI, DNS, HTTP and HTML.
3. You are familiar with the concepts of path and request parameter.
4. You know the basic structure of `GET` and `POST` type requests at the `HTTP` protocol level.
5. You will identify the parts of an HTTP response returned from the server.
