## WEB-Server-Programming-Java

### Prerequisites
- Programming Fundamentals (TKT10002)
- Advanced Programming Course (TKT10003) 
- Database Fundamentals (TKT10004)


### Course Parts Overview

| Part | Themes | Competence Objectives |
|------|--------|----------------------|
| **1** | Introduction to how web applications work and the basic components of the internet | • Know the basics of how the Internet works<br>• Familiar with concepts of URI, DNS, HTTP and HTML<br>• Familiar with concepts of path and request parameter<br>• Familiar with basic structure of GET and POST type requests at HTTP protocol level<br>• Recognize parts of HTTP protocol response from server<br>• Familiar with client-server model<br>• Know how to implement a simple server and browser<br>• Superficially familiar with Spring Boot application framework<br>• Know how to create a web application that responds to requests |
| **2** | Views, databases and database abstractions | • Use Thymeleaf library to create pages for views<br>• Send data to the server and process data sent to the server<br>• Familiar with POST/Redirect/GET design pattern<br>• Familiar with concept of ORM<br>• Utilize database abstraction provided by Java and Spring Boot for data processing<br>• Handle applications containing a single database table<br>• Familiar with concept of path variable and use path variables in applications |
| **3** | Databases and database abstractions. References between database tables, filtering and organizing results | • Handle applications containing multiple database tables<br>• Know how to define references between database tables<br>• Know how to handle transactions programmatically<br>• Familiar with N+1 query problem and methods to avoid it<br>• Know how to organize and limit information retrieved from database |
| **4** | Media types and file storage. Software development process, layered architecture and automated application testing. Moving an application to the web | • Know concept of media type and how to handle files in database<br>• Basic understanding of different stages of software development process<br>• Know architectural patterns suitable for web applications<br>• Understand layered architecture<br>• Know how to divide parts of application into services<br>• Write automatically executed tests for applications<br>• Know how to transfer application to the network for public access |
| **5** | HTTP protocol and cookies. Authentication and authorization | • Familiar with concept of statelessness<br>• Know what cookies are and their purpose<br>• Familiar with essential legal issues related to cookies<br>• Explain differences between authentication and authorization<br>• Create application that asks user to log in<br>• Define paths and methods that require logging in<br>• Hide parts of view from different user groups |
| **6** | Repeating structures and fragments. Using style sheets. Validating inputs. Interfaces and REST | • Know methods for defining and reusing recurring page structures<br>• Know what Twitter Bootstrap is and use it to define styles<br>• Know methods for validating data and validate form data<br>• Know concept of interface and REST interfaces<br>• Implement service that provides data over REST-formatted interface |
| **7** | Browser software and server software. A little bit of security. Application scalability. Reactive programming | • Know how to make JavaScript request to server from browser<br>• Update view displayed in browser based on JavaScript response<br>• Know most typical vulnerabilities in web applications (OWASP)<br>• Know methods for scaling applications for large user groups<br>• Know basics of reactive programming<br>• Create simple server software using reactive programming paradigm |
